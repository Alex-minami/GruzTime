# GruzTime — B2B landing prototype

Тестовая версия новой B2B-главной GruzTime для складов, распределительных центров, производств, ритейла и логистических операторов.

## Цель

Отсечь B2C-заявки на квартирные и бытовые переезды и сфокусировать посадочную страницу на корпоративных задачах:

- погрузочно-разгрузочные работы;
- аутсорсинг линейного персонала;
- складские переезды;
- такелажные работы.

## Структура

- `index.html` — семантическая структура страницы;
- `styles.css` — адаптивный дизайн без внешних зависимостей;
- `script.js` — мобильное меню и клиентская валидация формы;
- `.github/workflows/pages.yml` — публикация через GitHub Pages.

Форма на текущем этапе является прототипом: она проверяет заполнение полей, но не отправляет данные на сервер или в CRM.
